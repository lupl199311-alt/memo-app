# luplmemo

할일을 집중 타이머에 올리고, 완료하면 자동 체크되는 작은 메모 앱입니다. 데이터는 브라우저에 먼저 저장되고, Supabase 로그인 후 모든 기기에서 동기화됩니다.

## 사용 방법

1. 앱을 엽니다.
2. 이메일과 비밀번호로 가입 또는 로그인합니다.
3. 다른 폰이나 컴퓨터에서도 같은 이메일과 비밀번호로 로그인하면 같은 기록을 볼 수 있습니다.

할일 입력칸에 한 줄을 적고 `Enter`를 누르면 새 할일이 목록 맨 위에 바로 추가됩니다. 여러 줄을 한 번에 붙여넣으면 빈 줄은 건너뛰고 각각 별도의 할일로 만들어집니다. 새 할일은 AI 우선순위를 정하기 전까지 위에 남아 있고, 배정이 끝나면 우선순위 순서에 맞춰 이동합니다.

할일 목록의 각 항목에서 `AI`를 누르면 그 할일에 대해 `일 따오기`, `돈 관리`, `일정 조율`, `내부 업무` 중 하나를 고르고, 마감과 미루면 생기는 영향까지 버튼으로 답한 뒤 우선순위를 자동 배정합니다. 로그인하지 않아도 로컬 기준으로 정리되며, Supabase Edge Function이 연결된 로그인 상태에서는 AI 결과를 우선 사용합니다. 아직 AI 배정이 없는 할일은 목록 아래에 표시됩니다.

## 아이폰 단축어에서 할 일 받기

앱 주소 뒤에 `?todo=`와 URL 인코딩된 텍스트를 붙여 열면 텍스트가 새 할 일로 자동 추가됩니다. 한 번 읽은 내용은 주소창과 브라우저 기록에 남지 않도록 URL에서 제거됩니다.

단축어 동작 순서는 다음과 같습니다.

1. 기존 자동화에서 `메모에 추가`를 제거합니다.
2. 자동화가 만든 텍스트를 `URL 인코딩`합니다.
3. `URL` 동작을 추가하고 다음 주소를 입력합니다.

```text
https://lupl199311-alt.github.io/memo-app/?todo=
```

4. `=` 뒤에 `URL 인코딩 결과` 변수를 삽입합니다.
5. 마지막에 `URL 열기`를 추가합니다.

예를 들어 여러 줄 텍스트를 보내면 앱이 줄마다 별도의 할 일로 추가합니다. 링크를 여는 기기에서 스님 계정으로 로그인되어 있으면 Supabase에도 동기화됩니다. 로그인하지 않으면 해당 브라우저에만 저장됩니다. URL에 텍스트가 들어가므로 비밀번호나 민감한 정보는 보내지 않습니다.

Supabase Project URL과 anon/public key는 앱 코드에 들어 있습니다. `service_role` key는 절대 브라우저나 GitHub에 넣지 않습니다.

## Supabase 초기 설정

Supabase 프로젝트를 새로 만들 때는 SQL Editor에서 `supabase/schema.sql` 내용을 한 번 실행합니다.

AI 우선순위를 쓰려면 Supabase Edge Function `prioritize-todos`를 배포하고, Supabase Dashboard의 Edge Function Secrets에 `OPENAI_API_KEY`를 추가합니다. OpenAI 키는 브라우저 코드나 GitHub에 넣지 않습니다. 선택 사항으로 `OPENAI_MODEL`을 넣으면 기본 모델을 바꿀 수 있으며, 기본값은 비용이 더 낮은 `gpt-5.6-luna`입니다.

## 로컬 실행

```powershell
python server.py 4177
```

그다음 `http://localhost:4177/`로 접속합니다.
